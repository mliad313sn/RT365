# ADR-008 — Single code path for backtest and production
**Status:** Proposed · **Date:** 2026-09-07 · **Deciders:** ARB · **Provenance:** [Committee, derived from 08]

## Context
Backtest/paper divergence hides defects and bias.

## Decision
Backtest engine executes the production order, risk and eligibility code against a simulated broker.

## Alternatives considered
(a) Separate research engine — rejected: divergence. (b) Shared library — partial. (c) Same services in sim mode — chosen.

## Consequences
Backtest speed constraints; higher fidelity.

## Controls and tests affected
FR-08; R-03.
