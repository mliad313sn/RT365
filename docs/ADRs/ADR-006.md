# ADR-006 — Service mesh justification
**Status:** Proposed · **Date:** 2026-09-07 · **Deciders:** ARB · **Provenance:** [Source: 03 'where justified']

## Context
Mesh adds mTLS and policy but also complexity.

## Decision
Adopt mesh only for Control and Execution planes where mTLS and egress policy are mandatory; evaluate for Analytics at Gate B.

## Alternatives considered
(a) Mesh everywhere. (b) No mesh, library mTLS. (c) Selective — chosen.

## Consequences
Two security postures to document.

## Controls and tests affected
NFR-SEC-02.
