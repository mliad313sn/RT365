# ADR-007 — Regional cell topology
**Status:** Proposed · **Date:** 2026-09-07 · **Deciders:** ARB · **Provenance:** [Committee, derived from 03]

## Context
Failure domains and noisy-neighbour prevention.

## Decision
One cell per venue cluster; cell is the failure domain; cross-cell traffic limited to audit replication and portfolio roll-up.

## Alternatives considered
(a) Single global deployment — rejected: blast radius. (b) Cell per tenant — rejected: cost.

## Consequences
DR per cell; data residency simplified.

## Controls and tests affected
NFR-RES-01; DR_PLAN.
