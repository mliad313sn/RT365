# ADR-001 — Three-plane topology
**Status:** Proposed · **Date:** 2026-09-07 · **Deciders:** ARB · **Provenance:** [Committee, derived from 00, 03]

## Context
The blueprint mandates that only the Execution Gateway submits real orders and that analytics is isolated from execution.

## Decision
Group the 20 bounded contexts into Analytics, Control and Execution planes; deny any network route from Analytics to Execution or brokers; Analytics reaches Control only via the trade-intent queue.

## Alternatives considered
(a) Convention-only separation — rejected: not testable, drifts. (b) Single plane with RBAC — rejected: an injected agent could reach execution APIs. (c) Three planes with network policy — chosen.

## Consequences
Extra latency at plane boundaries; simpler threat model; injection blast radius confined to Analytics.

## Controls and tests affected
NFR-SEC-01; TC-NET-001..004; THREAT_MODEL boundary B3/B4.
